RemindRx — Tải app Android để test

Bản demo, cài trực tiếp trên điện thoại Android. App đã kết nối sẵn với backend thật đang chạy trên server.

⬇ Tải file APK

Cách cài:

  1. Tải file .apk ở nút trên bằng trình duyệt trên điện thoại Android.
  2. Mở file vừa tải. Nếu Android hỏi "Cài ứng dụng không rõ nguồn gốc" (unknown sources), bấm Cho phép / Cài đặt — bình thường vì app chưa lên Google Play.
  3. Mở app, đăng nhập bằng số điện thoại demo 0900000000, mã PIN 123456.

Dữ liệu trong bản demo chỉ là dữ liệu mẫu — không nhập thông tin bệnh nhân thật. Cần điện thoại Android thật (không cài được trên iPhone).
